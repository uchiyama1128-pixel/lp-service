LINE チャンネル情報
▶ LINE公式アカウントをまだ作っていない方はここを開いてください

【STEP A】LINE公式アカウントの作成（無料）

  1. LINE公式アカウント開設ページ を開く
  2. 「無料で始める」をクリック
  3. 個人のLINEアカウントでログイン（または新規作成）
  4. アカウント名・業種・国を入力して「確認する」→「完了」

【STEP B】Messaging APIチャネルの作成

  1. LINE Developers Console を開く
  2. 同じLINEアカウントでログイン
  3. 「プロバイダーを作成」→ プロバイダー名（院名など）を入力
  4. 「チャネルを作成する」→「Messaging API」を選択
  5. チャネル名・説明・業種を入力して「作成」
  6. 「LINE公式アカウントと連携しますか？」→ 先ほど作ったアカウントを選択して「OK」

✅ ここまで完了したら、次の「取得手順」に進んでください

取得手順（チャンネルをお持ちの方）

  1. LINE Developers Console を開く
  2. 作成したプロバイダー → Messaging APIチャネルを選択
  3. 「チャネル基本設定」タブ → チャネルID（数字）とチャネルシークレットをコピー
  4. 「Messaging API設定」タブ → ページ下部の「チャネルアクセストークン（長期）」の「発行」をクリックしてコピー
  5. 「Messaging API設定」タブ → Webhook設定 欄で以下を行う：
    • Webhook URLに下のURLをコピーして貼り付け
    • 「Webhookの利用」を ON にする
    • 「検証」ボタンで接続確認（成功と表示されればOK）
